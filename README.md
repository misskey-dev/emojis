# Emojis for Misskey

Misskey で使用する絵文字関連をまとめたパッケージです。以下のパッケージで構成されています。

- `@misskey-dev/emoji-assets`: 絵文字（Twemoji, Fluent Emoji）のアセットがパッケージ化されています。
- `@misskey-dev/emoji-data`: 絵文字のデータや検索用インデックス、正規表現を提供します。

**ほかのプロダクトで使用されることは想定していません。サポートや要望への対応は、脆弱性に関わる問題を除き、原則として行いませんので予めご了承ください。**

---

This package contains emoji assets and related utilities for Misskey. The package is composed of the following sub-packages:

- `@misskey-dev/emoji-assets`: This package contains emoji assets (Twemoji, Fluent Emoji).
- `@misskey-dev/emoji-data`: This package provides emoji data, search indexes, and regular expressions.

**This package is not intended for use within other products. Please note that we do not provide support for such use cases, except for security issues.**
